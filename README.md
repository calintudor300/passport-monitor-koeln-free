# Passport Monitor Köln — полностью бесплатная версия PWA

**Никакого Railway, VPS или платного домена.** Сайт и push-раздача работают на **Cloudflare Workers Free + KV Free**; браузерная проверка формы работает по расписанию на **GitHub Actions в публичном репозитории**. Телефон может быть заблокирован, приложение закрыто. Запись не выполняется автоматически.

**Проверка по умолчанию — четыре раза в час (примерно каждые 15 минут)**. GitHub Actions иногда опаздывает или пропускает запуск. У публичного репозитория расписание отключается после 60 дней без активности — его нужно возобновить вручную. GitHub Actions не гарантирует круглосуточную надёжность.

**Важное ограничение:** живой браузер не протестирован на защищённой динамической форме сайта. Если интерфейс изменился, появилась CAPTCHA или блокировка автоматизации, обнаружение дат может не работать. В этом случае в приложении будет «Неизвестно»/«Ограничен доступ», а не ложное «Нет мест». Сигнал «доступно» появляется только при появлении вариантов в поле «Обрати день» после выбора услуги.

## Начало работы

Прочитайте **`НАСТРОЙКА_БЕЗ_ОПЛАТЫ.md`**. Его можно открыть прямо из ZIP-архива. Вам понадобятся только бесплатные аккаунты GitHub и Cloudflare, браузер и отдельный файл `Passport_Monitor_FREE_СЕКРЕТЫ.txt`, который передаётся вместе с ZIP, но намеренно **не включён в ZIP**. **Никогда не публикуйте файл секретов на GitHub**.

Если хотите проверить программу перед размещением, установите Node.js 20+ и запустите:

```bash
npm run syntax
npm test
```

Состав проекта: `worker.js` — личная PWA и отправка Web Push; `public/` — сайт и Service Worker; `.github/workflows/check.yml` — GitHub Actions; `src/monitor.cjs` и `src/classifier.cjs` — Playwright и логика определения дат; `scripts/check.cjs` — передача результата в Cloudflare; `wrangler.jsonc` — настройки Workers/KV.
